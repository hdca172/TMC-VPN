Cómo descargar e instalar

  1. Abre GitHub Actions desde el botón superior e inicia sesión en GitHub si te lo solicita.
  2. Selecciona una ejecución de la rama main con estado Success.
  3. En Artifacts, descarga TMC-VPN-V4.5-debug.
  4. Extrae el ZIP y abre app-debug.apk en tu Android.
  5. Autoriza temporalmente la instalación desde esa fuente si Android lo solicita y revoca ese permiso después.

Solo para pruebas. Este APK debug no es una versión de producción firmada. Los artefactos pueden caducar a los 30 días. No descargues APK de enlaces de terceros.

Antes de conectarte

Necesitas un perfil WireGuard .conf válido para un servidor propio o autorizado y una conexión a Internet existente. Una VPN no proporciona datos móviles gratuitos.

Importa tu perfil, selecciona el proveedor o servidor, concede el permiso VPN de Android y comprueba la navegación y el DNS.
